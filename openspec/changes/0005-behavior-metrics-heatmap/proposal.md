# Предложение: Сбор поведенческих метрик и хитмэп в админ-панели

## Цель

Собирать метрики поведения посетителей на главной странице Luxury-Auto (время на странице, клики по кнопкам, позиции курсора) и показывать администратору статистику с визуальной хитмэп-картой популярности областей экрана.

## Область изменений

- новая таблица `behavior_metrics` — одна строка на визит посетителя;
- публичный `POST /api/behavior-metrics/` для приёма метрик с главной страницы;
- защищённый JWT `GET /api/behavior-metrics/stats` со статистикой по периодам и точками курсора;
- скрипт сбора метрик на главной странице: секунды на странице, счётчик кликов по кнопкам, позиция курсора раз в секунду;
- отправка накопленных метрик `POST`-запросом раз в секунду;
- кнопка «Статистика» в админ-панели и полноэкранное модальное окно:
  - среднее и максимальное время на странице за день, неделю и месяц;
  - canvas-хитмэп точек курсора (полупрозрачные круги, наложение даёт «тепло»).

## Контракт POST /api/behavior-metrics/

```json
{
  "session_id": "uuid-визита",
  "application_id": 0,
  "time_on_page": 0,
  "buttons_clicked": "string",
  "cursor_positions": "string",
  "return_frequency": 0
}
```

- `application_id` всегда `0`, `return_frequency` всегда `0` (по требованию);
- `buttons_clicked` — JSON-строка вида `{"Рассчитать обслуживание": 2}`;
- `cursor_positions` — JSON-строка вида `[{"x": 12.5, "y": 40.0}]`, координаты в процентах окна (0–100), чтобы хитмэп был сопоставим на разных экранах;
- `session_id` — дополнительное поле (UUID, генерируется на клиенте при загрузке страницы): без него ежесекундные POST-запросы плодили бы по строке в секунду; backend обновляет существующую строку визита по `session_id`.

## Правила доступа

- `POST /api/behavior-metrics/` публичный (посетители главной страницы не авторизованы);
- `GET /api/behavior-metrics/stats` требует JWT администратора.

## Вне области

- аналитика заявок (`lead_analytics`) — остаётся как есть;
- запись видео/скриншотов экрана — сохраняются только координаты курсора;
- персональные данные посетителей (IP, user-agent) в метриках;
- фильтры хитмэпа по периодам и экспорт статистики.

## Критерии готовности

- главная страница раз в секунду отправляет накопленные метрики в `POST /api/behavior-metrics/`;
- повторные запросы того же визита обновляют одну строку в `behavior_metrics`;
- `GET /api/behavior-metrics/stats` возвращает среднее/максимальное время за день, неделю, месяц и список точек курсора;
- без JWT `GET /stats` возвращает 401;
- в админ-панели кнопка открывает полноэкранное окно с тремя периодами и хитмэпом;
- при отсутствии данных статистика корректно показывает нули/пустую карту.
