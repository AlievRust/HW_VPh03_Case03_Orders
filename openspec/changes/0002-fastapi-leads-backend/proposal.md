# Backend для заявок и аналитики

## Цель

Добавить приватное FastAPI-приложение для приёма заявок тёплых клиентов, метрик поведения frontend и административных настроек интерфейса.

## Область изменений

- Создать backend в каталоге `backend/`.
- Добавить SQLAlchemy-модели PostgreSQL и CRUD-классы рядом с моделями.
- Добавить отдельные FastAPI-роутеры для каждой модели.
- Объединить роутеры в `main.py`.
- Подключить backend к существующей PostgreSQL через Docker private-сеть.
- Проксировать API через Nginx по `/api/`.
- Не публиковать порт backend на хосте и не выводить PostgreSQL наружу.

## Сущности

- `leads` — контактные и бизнес-данные заявки.
- `lead_analytics` — агрегированные и событийные метрики поведения, связь один-к-одному с заявкой.
- `admin_settings` — услуги и диапазоны бюджета для динамического frontend.

## Вне области

- Авторизация пользователей frontend.
- Административная авторизация.
- Alembic и версионирование миграций.
- TLS для внутреннего учебного HTTP-контура.
- Публичная публикация backend-порта.

## Критерии успеха

- Backend запускается в Compose и подключается к PostgreSQL.
- Таблицы создаются при старте приложения.
- Frontend может отправить заявку единым JSON-пакетом.
- Аналитика сохраняется отдельно и связывается с заявкой.
- Настройки можно читать и изменять через API.
- Backend доступен только через Nginx `/api/`, прямого host-порта нет.
