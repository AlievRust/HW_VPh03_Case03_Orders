# Luxury-Auto frontend

## Цель

Заменить HTML-заглушку на собранный npm/Vite frontend Luxury-Auto с премиальной главной страницей, формой заявки на обслуживание автомобилей и отправкой данных в существующий FastAPI API.

## Объём

- Создать минимальный Vite-проект в каталоге `frontend/`.
- Собрать адаптивную страницу Luxury-Auto в `frontend/dist`.
- Добавить визуальную систему с тёмным графитовым фоном, золотыми акцентами, округлым шрифтом Google Fonts и ненавязчивой анимацией полупрозрачных золотых кругов.
- Разместить на главной странице шапку бизнеса, блок услуг и форму заявки.
- Подключить форму к `POST /api/leads`.
- Собрать технические и поведенческие показатели, предусмотренные backend-схемой.
- Настроить Nginx на раздачу `frontend/dist`.

## Не входит в изменение

- Авторизация администратора.
- Личный кабинет клиента.
- Изменение моделей или API backend.
- Онлайн-оплата, запись в календарь и интеграции с CRM.
- Добавление стороннего UI-фреймворка.

## Пользовательское поведение

Посетитель сразу видит позиционирование Luxury-Auto, ключевые услуги и форму заявки. Он выбирает тип обслуживания, параметры автомобиля и удобный способ связи, после чего отправляет запрос. При успешной отправке отображается подтверждение и номер заявки; при ошибке показывается понятное сообщение без потери введённых данных.

## Успешный результат

- `npm install` и `npm run build` завершаются успешно.
- Nginx отдаёт собранный frontend из `frontend/dist`.
- Форма отправляет валидный JSON в `/api/leads`.
- Страница работает на desktop и mobile без горизонтального скролла.
