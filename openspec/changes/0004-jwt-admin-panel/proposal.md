# Предложение: JWT-авторизация и админ-панель услуг

## Цель

Добавить защищённую админ-панель Luxury-Auto по адресу `/admin/` для управления услугами из таблицы `admin_settings`.

## Область изменений

- создать таблицу администраторов `admin_users`;
- добавить регистрацию первого администратора;
- добавить вход по логину и паролю;
- выдавать JWT access-токен сроком на 60 минут;
- разрешить авторизованному администратору добавлять новых администраторов;
- закрыть административные операции JWT-авторизацией;
- реализовать frontend админ-панели с CRUD услуг.

## Правила доступа

- публичная регистрация доступна только если в `admin_users` нет записей;
- после появления первого администратора публичная регистрация отключается;
- авторизованный администратор может создавать новых администраторов;
- `GET /api/admin-settings` остаётся публичным для основного сайта;
- `POST`, `PUT`, `DELETE /api/admin-settings` требуют JWT;
- `POST /api/leads` остаётся публичным;
- `GET`, `PUT`, `DELETE /api/leads` требуют JWT;
- админские auth endpoints доступны без JWT согласно их назначению.

## Вне области

- refresh-токены;
- восстановление пароля;
- роли и разграничение прав между администраторами;
- физическое удаление администратора из интерфейса.

## Критерии готовности

- первый администратор регистрируется только при пустой таблице;
- повторная публичная регистрация возвращает отказ;
- вход возвращает JWT;
- JWT защищает административные API;
- `/admin/` показывает вход, регистрацию только при отсутствии админов и CRUD услуг после входа;
- основной сайт продолжает публично загружать активные услуги и принимать заявки.
