# История изменений

- Зафиксировано название бизнеса: Luxury-Auto.
- Добавлен npm/Vite frontend Luxury-Auto с адаптивной формой заявки, аналитикой поведения и премиальным визуальным стилем.
- Добавлена JWT-авторизация администраторов, таблица `admin_users` с nickname и админ-панель `/admin/` для CRUD услуг.
- Публичная регистрация ограничена первым администратором; последующих администраторов можно добавить из защищённой панели.
- В Nginx добавлена явная выдача `/admin/` из `admin.html`: SPA-fallback на `index.html` возвращал главную страницу сайта вместо формы входа.
- Сборка frontend очищает `frontend/dist` перед копированием новых файлов, поэтому ассеты прошлых сборок больше не накапливаются.

## 0005-behavior-metrics-heatmap

- Главная страница раз в секунду отправляет поведенческие метрики (время на странице, клики по кнопкам, позиция курсора) в публичный `POST /api/behavior-metrics/`.
- Добавлена таблица `behavior_metrics`: один визит — одна строка, ежесекундные запросы обновляют запись по `session_id` (upsert).
- Добавлен защищённый JWT `GET /api/behavior-metrics/stats`: среднее/максимальное время за день, неделю и месяц плюс точки курсора.
- В админ-панели кнопка «Статистика» открывает полноэкранное окно с карточками периодов и canvas-хитмэпом позиций курсора.
- Обновлены устаревшие тесты `test_api.py`, ожидавшие публичный доступ к endpoints, закрытым JWT ещё в change 0004.

## 0001-docker-infrastructure

- Добавлена Docker Compose-инфраструктура с Nginx, PostgreSQL, pgAdmin, приватным HTTP Docker Registry и Watchtower.
- PostgreSQL изолирован во внутренней Docker-сети, а pgAdmin доступен через Nginx.
- Добавлены шаблон переменных окружения, исключение секретов Registry и инструкции по `docker login` и публикации образов.
- Добавлен подробный README с архитектурой, настройкой, эксплуатацией и типовыми проблемами; конфигурационные файлы снабжены русскоязычными комментариями.
- Каталоги `frontend/` и `registry/auth/` зафиксированы в Git файлами `index.html` и `.gitkeep`, поэтому они создаются автоматически после клонирования или `git pull`.
- В README и техническом обзоре добавлены Linux/bash-эквиваленты команд (создание `htpasswd` через `>`, `cp`, `curl`, `test -f`) и разбор ошибки `Out-File: command not found`.
- Обновлен образ Watchtower до `latest`, добавлена переменная `DOCKER_API_VERSION=1.40` для совместимости с Docker daemon и команды обновления контейнера.
- Добавлен приватный FastAPI backend для заявок, аналитики и административных настроек; его порт не публикуется, внешний API доступен через Nginx по `/api/`.
